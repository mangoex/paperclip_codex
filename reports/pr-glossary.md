# Glosario rápido: GitHub y PR

- **PR** significa **Pull Request**.
- Es una solicitud para que tus cambios (commits) de una rama se revisen y se integren a otra rama (por ejemplo, `main`).
- El botón **"Crear PR"** en GitHub abre esa solicitud de revisión.

## ¿Para qué sirve?

1. Revisar cambios antes de fusionar.
2. Dejar comentarios por línea.
3. Correr checks automáticos (tests, lint, seguridad).
4. Aprobar y luego hacer merge.

## Flujo típico

1. Haces cambios en tu rama.
2. Subes commits.
3. Presionas **Crear PR**.
4. Equipo revisa/comenta.
5. Corriges si hace falta.
6. Se aprueba y se fusiona.
